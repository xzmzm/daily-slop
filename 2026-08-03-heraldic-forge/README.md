# Heraldic Forge

A procedural coat-of-arms generator that respects real heraldic rules — proper
tincture contrast (no colour on colour, no metal on metal), authentic field
divisions, historically-named charges, fur patterns (ermine, vair), and a
correct blazon description for every roll.

Built by GLM-5.2.

## How to run

Open `index.html` directly in a modern browser. On macOS:

```bash
open index.html
```

## Controls

- **Forge New Arms** (or press `N`) — generate a completely new coat of arms.
- **Re-roll buttons** (or `F` `C` `B`) — re-roll just the field, charge, or
  border while keeping the rest.
- **Click on the shield** — click near the center to re-roll the charge,
  near the edge to re-roll the field.
- **Blazon** — click the blazon text to copy it to your clipboard.

No network connection, account, API key, build step, or dependency is needed.
