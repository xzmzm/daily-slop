# NOTES — Straight Line 1927

## Why this project?

九月七日翻纪念日：1533 伊丽莎白一世生辰、1812 博罗季诺（大兵团伤亡模拟，
和之前的火山、海战比没有新的闭式机器）、1940 伦敦大轰炸开始（题材太沉）、
1979 ESPN 开播、1996 图帕克中枪——然后是它：**1927 年 9 月 7 日，
法恩斯沃斯在绿街 202 号传出第一张全电子电视图像，一条直线**，99 周年。
前一天刚做过 1776 海龟号，本来担心「历史之夜」连续两天会腻，但这条直线
的物理面完全没被这个仓库碰过：采样/扫描、带宽平方律、NTSC 分数链。
旧的 weaf-660 是调幅广播、lathe-cut 是音频纹轨，都不占「用行把图像拆开」
这个格子。就它了。

（内置 web 搜索这周限额耗尽，9/13 才恢复；改走本机 Codex 搜索端点核实了
日期、地点、加德纳转玻璃片、TIME 的「涂黑玻璃刻线」细节，多源一致。）

## How it works

全部数字出自 `physics.js`，页面只是渲染；`__demo` API 供录屏使用。

**带宽定律**：水平分辨率配平竖直（都打 Kell 0.7 折扣）时，最高视频频率
`B = AR·K·n_v/(2·T_active)`。NTSC：1.333×0.7×480/(2×52.4 µs) = 4.27 MHz，
对着史载 4.2 MHz，误差 1.6%——这是全页最舒服的一次落点。贝尔德 30 行
（竖画幅 7:3）9.19 kHz，真的塞得进中波电台的声音频道。测试还抓了一个
结构性事实：**每个真实制式的史载带宽都 ≥ 平衡值**（英国人给 405 行买了
3 MHz，水平分辨率比竖直富余一半）——定律是「平衡下限」，不是「实际值」。

**NTSC 分数链**（本日最漂亮的发现）：三条浮点恒等式精确成立——

```
4.5e6/286/525 === 30000/1001        （帧率 29.97…）
227.5 × (4.5e6/286) === 315e6/88    （副载波 3.579545… MHz）
```

不是近似：227.5 = 455/2，而 455/572 = 35/44，于是 4.5e6×35/44 = 315e6/88。
1953 年的委员会把三个约束（副载波半行偏置、声音整数行、4.5 MHz 不动）
锁成一组丢番图方程，解出来整条链全是漂亮分数，帧率被拽下 0.1%。
时码丢 108 帧补 3.600 s，实际漂移 3.5964 s——**每小时多补 3.6 毫秒，
一个月攒 2.6 秒**，这个残余是测试算出来的，我事先不知道。

**点阵反转**：副载波 227.5 周期/行 → 相邻行相位差正好半周期，点阵明暗
互换；一场 262.5 行 → 场间差 0.75 周期（= −0.25，四场闭合）。测试用的
「两行正弦相加为零」在整数行上平凡成立，改成 10.25/11.25 行才真的检验了
反转——第一版测试是假测试，抓的是 0 = 0。

**萤光屏**：软件帧缓冲（432×324 的 Uint8ClampedArray），每行写入绿荧光
RGB，按 `exp(−dt/τ)` 衰减；τ 随帧率走（`max(90ms, 2.2/fps)`），否则
12.5 fps 时上一帧的行衰减到 41%，画面一闪一闪像坏了。亮度用 `max` 合成
（萤光只亮不暗），当前行画部分线加亮点。第一版每行调一次 `getImageData`
读源图，1080 行时每帧上千次强制回读，卡成幻灯片——改成脏标记：
只在底片或转角变化时整幅重算亮度网格，扫描时只查表。

## Interesting notes

- **掉进去的坑（一）**：我一开始把「场率」当滑块语义，隔行开着时行频会
  翻倍，公式卡和波形对不上。改回「帧率」滑块 + HUD 里显示 `场 f/2`，
  语义才自洽：f_line = N × 帧率，不管隔不隔行。
- **掉进去的坑（二）**：视觉模型审截图说 CRT「极其昏暗」，差点去调亮度。
  数了像素才发现那行绿线峰值就是 255、亮像素 1900 个——是「截图里一根
  细线在黑底上显得暗」，不是渲染 bug。教训复用海龟号那天的：数字先于
  眼睛。顺手加了一层 shadowBlur 泛光，视觉上更像显像管。
- 819 行制式最初写错成「香农的高清」——是 Henri de France 的系统。
  测试没抓这个（它只管数字），是写 README 时自己发现的。
- 「美元符号」作为 1928 年报界演示的图像出自 Everson 的记载与 TIME 的
  报道，多源一致，但学界有人认为那场演示送出的第一张图是别的——时间线
  文案用「最早送出的图像之一」，不赌。
- YIQ 系数取 1953 年 FCC 的四位小数版：Y 行和恰好 1，I/Q 行和恰好 0
  （0.5959 = 0.2746+0.3213，0.5227 = 0.2115+0.3112），于是「白点无色」
  是 1e-12 级断言而不是 1e-4。彩条亮度阶梯 1.000/0.886/0.701/…全部由
  Y 行系数精确组合，0.299+0.587 = 0.886 就是黄条。
- 没做的：矢量示波器只画了色调旋转，没有饱和度旋钮和色同步脉冲；
  尼普科夫圆盘没有动画（只有数字判词）；1927 年解剖管的电子光学
  （光电子加速、偏转线圈扫描）整段没建——那是另一天的题目。
