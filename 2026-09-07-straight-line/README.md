# Straight Line 1927 · 电子电视的第一张图

> Built by GLM-5.3

九十九年前的今晚——1927 年 9 月 7 日——旧金山绿街 202 号，21 岁的法恩斯沃斯把
涂黑玻璃上的一道直线送进「影像解剖管」，电流在隔壁房间又拼回一条会动的线：
第一张全电子电视图像。本届四个房间：把画犁成行的扫描器、行数平方的带宽定律、
1953 年 3.579545 MHz 的兼容彩色折衷，和一条从尼普科夫圆盘到模拟关机的时间线。

## How to run

直接双击打开 `index.html`，或者：

```bash
python3 -m http.server 8765     # 在仓库根目录
```

然后访问 <http://localhost:8765/2026-09-07-straight-line/>。
（8000 端口在本机是保留端口，不要用。）

## 四个房间

1. **解剖一条直线** — 重演那一晚：左边是玻璃底片，中间是这一行的复合信号
   （同步 −40 IRE、消隐、图像 0–100 IRE），右边是萤光屏，像素逐行点亮、
   按 P1 萤光余辉衰减。行数从 30 拉到 1080，帧率、隔行随便拨；
   「转动玻璃片 90°」就是加德纳那一下——线跟着立起来，图像才成为图像。
   诚实折扣叫 Kell 因子：扫描 480 行，眼睛只拿到 0.7×480 = 336 行。
2. **行数的平方** — 水平分辨率配平竖直之后，视频带宽是闭式
   `B = AR·K·n_v/(2·T_active)`：行数×2 → 带宽×4。贝尔德 30 行 9.2 kHz
   塞进中波声音频道；美国 525 行 4.2 MHz；数字 1080p60 采样时钟 148.5 MHz
   （精确）。同一页给出机械的死路：圆盘边缘速度 πD·帧率、每像素 37 µs
   （30 行）对 82 ns（525 行）——硒光电池差三个数量级，电子束没有惯性。
3. **兼容彩色** — 一亿台黑白机已经在了，于是亮度 Y 原样发、色度骑在
   227.5 倍行频的副载波上（奇半整数，点阵逐行反转、眼睛自动平均成灰）；
   声音 4.5 MHz 保持 286 倍行频（整数，安静）。整条链是精确分数：
   行频 = 4.5 MHz/286，帧率 = 30000/1001 = 29.97，副载波 = 315/88 MHz。
   转动「色调」，矢量示波器整把扇子旋转、亮度阶梯纹丝不动；
   时码从此每小时丢 108 帧（补偿 3.600 s，漂移 3.5964 s——多补的 3.6 ms/h
   是留给历史的幽默）。
4. **时间线** — 1884 尼普科夫专利、1926 贝尔德 30 行、1927.9.7 一条直线（★）、
   1928 美元符号、1935 黑板草图定优先权、1936 BBC 405 行、1939 RCA 低头、
   1941 五二五行、1953 兼容彩色、1969 六亿人看月亮、2009 模拟关机。

## Tests

```bash
node --test test_physics.mjs
```

23 个断言组：闭式带宽对逐步链条（每制式 1e-12）、525 行落 4.27 MHz、
30 行装进 10 kHz 频道、N² 律、Kell 336、1080p60 采样时钟精确 148.5 MHz、
圆盘边缘速度与马赫、硒光电池差三个数量级、点亮占比 1/2100、
精确分数链（4.5e6/286、30000/1001、315e6/88 浮点恒等）、隔行 262.5 行、
点阵逐行反转 ±0.5 周期、丢帧 108 与 3.6 ms/h 过补偿、YIQ 行和恒等、
白点无色、矩阵往返 1e-12、彩条亮度阶梯精确且严格递减、色调旋转只转色度、
时间线递增且唯一主角。

## 史实与重建的边界

1927 年 9 月 7 日、绿街 202 号、21 岁、涂黑玻璃刻直线、加德纳转动玻璃片、
日志「这次的线图清楚收到了」、1928 年向报界演示（美元符号）、1935 年优先权
裁定、1939 年 RCA 取得授权、1941 年 525 行、1953 年 12 月 17 日 FCC 批准
兼容彩色、1969 年约六亿观众、2009 年 6 月 12 日模拟关机——都出自通行记载。
各制式的带宽/行数/帧率为史载值；Baird 30 行的 7:3 竖画幅、Kell 0.7、
各制式消隐比例取工程常用值。萤光余辉 τ、点阵放大倍数是展示拟合，
不参与任何断言。
