# Pearl Street 110 · 铜的一万倍

1882 年 9 月 4 日下午三点，爱迪生在 J.P. 摩根的办公室拉下开关，106 盏灯亮起 ——
世界第一座商用电站（257 珍珠街）开始供电：59 家客户、400 盏灯、六台 27 吨的
「巨象」发电机、110 伏直流。这是 144 周年纪念的一座电网物理工作室：一根铜线
为什么把爱迪生的世界锁死在一平方英里，电压又怎么把它解开。整课都是闭式公式。

Built by GLM-5.3

五个房间：

1. **铜的定律** —— 馈线链 A = 2ρLP/(ΔV·V)、m = 4ρρ_m L²P/(ΔV·V²) 的实时
   双对数图：铜质量沿 1/V² 下坠。送 100 千瓦过 908 米（一平方英里的等价圆），
   一根主馈线就是 2,846 mm² 的铜、6 厘米粗、46 吨 —— 比驱动它的 27 吨「巨象」
   还重七成。1882 珍珠街 / 1891 劳芬—法兰克福 / 2019 昌吉—古泉三个预设，
   各自拟合到有据可查的线路参数。
2. **沿街的黄昏** —— 珍珠街配电示范：合闸后灯沿街次第亮起；把 2,000 盏灯全挂
   街尾，压降 18.18 V，街尾 91.8 V、亮度 54%、寿命 ×10.5；换成均匀铺满，
   逐段积分（三角形对矩形）给出**恰好一半**的压降 9.09 V。灯的亮度随 V^3.4、
   寿命随 V^−13 —— 街尾的灯最暗，也最耐用。
3. **110 伏的出身** —— 灯就是 P = V²/R：133 Ω 热丝在 110 伏上正好是 91 瓦，
   200 Ω 就是后来的 60 瓦灯泡；六台巨象满发 600 千瓦 = 6,600 盏灯 = 5,455 A。
   高电阻碳丝是配电经济学的开关，110 伏是灯的化学和铜的经济学中间的一格。
4. **半径与电压** —— 固定铜截面的可达距离是双对数图上斜率 1 的直线：同一根
   2,846 mm² 的主馈线，110 伏送 0.9 公里，15 千伏送 124 公里，±1.1 兆伏送
   9,080 公里。五条真实线路（珍珠街 → 劳芬 → 尼亚加拉 → 胡佛坝 → 昌吉—古泉）
   撒在同一场坐标里，各自带自己的铜，朝同一个方向爬。
5. **时间线** —— 1882 合闸 → 1884 的 508 家客户 → 1886 斯坦利的变压器 →
   1890 大火（9 号巨象幸存）→ 1891 劳芬 → 1893 芝加哥世博会 → 1896 尼亚加拉
   → 2007-11-14 曼哈顿最后一根直流馈线（125 年）→ 2019 昌吉—古泉：笑到最后的
   又是直流，只是电压高了一万倍。

历史参数取有据可查的数字（功率、电压、距离、效率）；铜的截面是拟合参数，
让闭式公式精确落在「一平方英里」「175 公里」「3,293 公里」上（测试锁定）。
三线预设的昌吉按单极回路折算（8×1,250 mm² 钢芯铝绞线），是诚实的类比而非
工程设计书。

## How to run

零依赖、无构建。因为用了 ES modules，需要起一个本地静态服务（别用 8000 端口）：

```bash
python3 -m http.server 8765        # 在仓库根目录
# 打开 http://localhost:8765/2026-09-04-pearl-street/
```

跑引擎测试（22 项，全部是精确断言）：

```bash
cd 2026-09-04-pearl-street && node --test test_physics.mjs
```
