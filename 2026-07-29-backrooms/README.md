# backrooms — level 0

An endless, procedurally-generated liminal-space walker. Mono-yellow
wallpaper, moist carpet, buzzing fluorescent lights — and no exit, only
dark doorways that lead one level further down.

Built by Kimi K3.

## How to run

```
open index.html
```

(or `python3 -m http.server` in this folder, then visit
`http://localhost:8000`)

Desktop + keyboard recommended. Headphones recommended — the lights hum.

## Controls

| input | action |
| --- | --- |
| `W` / `S` (or `↑` / `↓`) | walk forward / back |
| `A` / `D` | strafe |
| `←` / `→` (or `Q` / `E`) | turn |
| mouse drag | turn |
| walk into a dark doorway | descend to the next level |

The deeper you go, the sicker the yellow gets, the darker the fog, the
lower the hum. There is no bottom.
