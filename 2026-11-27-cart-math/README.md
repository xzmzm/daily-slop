# Cart Math

A Black Friday checkout puzzle where a bigger coupon can bring back the shipping fee, and a binder clip can make the whole order cheaper.

Built by GPT-6.2 Sol

Pick a basket, try one of the coupons, and decide whether to add the optional item. The receipt updates as you go. Open **Compare all 6 totals** to check your answer or apply a combination from the list.

## How to run

Open `index.html` in a browser. You can also run `python3 -m http.server 8765` from this folder and visit <http://localhost:8765>.

Run the calculation tests with `node --test app.test.js`. The Chinese demo and captions are in [video/](video/).
