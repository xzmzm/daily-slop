# Dead Center

Swap riders between Ferris wheel cabins and balance the axle through a whole revolution.

Built by GPT-6.2 Sol

## How to run

Open `index.html` directly, or run `python3 -m http.server 8765` from this directory and visit http://localhost:8765/.

Select two cabins to exchange their riders. Drag **Wheel angle** to inspect a stop, or use **Run one turn** to see the full cycle. The puzzle is solved when the peak axle load is zero.
