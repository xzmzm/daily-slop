# Forward Pass 1906 · 第一传的物理

1906 年 9 月 5 日，圣路易斯大学的罗宾逊在一场 22 比 0 的比赛里掷出美式橄榄球史上
第一记合法前传——第一掷落地未接（按当年规则直接转交球权），随后他找到施奈德，
20 码达阵。前传被合法化不是因为好看，是因为 1905 年那个赛季死了 19 个人。
这是 120 周年的一座传球物理工作室：一道有阻力的抛物线、一个会进动的陀螺，
和一台封顶 158.3 的评分机器，整课闭式公式。

Built by GLM-5.3

四个房间：

1. **一传的抛物线** —— R = (v cosθ/g)(v sinθ + √(v²sin²θ+2gh))，出手高度把最佳角从
   45° 拉到 θ* = arctan(v/√(v²+2gh))：55 mph、1.9 米出手，真空最远 69.4 码 @ 44.1°；
   尖头螺旋 C_D ≈ 0.10（一颗圆球的四分之一）把它收到**正好 60 码** @ 42.9°（滞空
   3.39 s，最高 15.1 m），同一记 55 mph 平射 18° 只有 42 码。RK4 与闭式现场对表：
   关掉阻力后只剩落地插值的残差（相对 ~10⁻⁶）。三个预设各自拟合到自己的落点：
   第一传 39.3 mph @ 12° = 20.00 码；55 mph 平射；60 码炸弹 = 55 mph @ 42.9°。
2. **螺旋是陀螺** —— 均匀密度长椭球 I_a = (2/5)mb²、I_t = (1/5)m(a²+b²)（比值 1.87）；
   炮弹稳定判据 s = I_a²ω²/(2 I_t M_α)：55 mph 下临界自转 **3.03 圈/秒**，NFL 出手的
   10 圈/秒 s ≈ 10.9。空气的颠覆力矩不把球掀翻，而让鼻尖以 Ω = τ/(I_aω) 缓慢进动、
   追着速度方向走（5° 偏角下 46.8 s 才转一圈；转速掉到 2 圈/秒快五倍）。后视图
   八分之一慢放里，晃动随 s 跨过 1 由发散变收敛；弃踢端对端绕横轴慢转，C_D ≈ 0.75。
3. **158.3 的配方** —— 1973 年名人堂 Don Smith 的传球者评分：四项各夹进 [0, 2.375]
   （完成率 30%→0、77.5%→满；YPA 3→0、12.5→满；TD% 11.875%→满；被截率 9.5%→0），
   求和 /6 ×100。四条基线（50% / 7.0 码 / 5% / 5.5%）恰好各得 1.0 → 66.7；完美一场
   = 158.3，天花板焊死，再好的数据也顶不破。曼宁 2004（336/497 · 4,557 码 · 49 TD ·
   10 INT）= 121.1、罗杰斯 2011（343/502 · 4,643 码 · 45 TD · 6 INT）= 122.5，
   测试逐项对表到小数点后一位。
4. **时间线** —— 1905 死亡赛季 → 白宫会议 → **1906-09-05 第一传**（五角星）→
   圣路易斯 11–0 → 1912 达阵 6 分 / 四档 → 1934 瘦球 → 1973 评分上线 → 1978 五码
   撞人线 → 2004 曼宁 → 2011 罗杰斯；贪心两行标签，图钉点开看那一年。

## How to run

零依赖、无构建。因为用了 ES modules，需要起一个本地静态服务（别用 8000 端口）：

```bash
python3 -m http.server 8765        # 在仓库根目录
# 打开 http://localhost:8765/2026-09-05-spiral-pass/
```

跑引擎测试（20 项，全部是精确断言）：

```bash
cd 2026-09-05-spiral-pass && node --test test_physics.mjs
```
