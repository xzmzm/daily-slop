# Seed Turn

Change the angle between sunflower seeds, then trace the curves that appear at the golden angle.

Built by GPT-6.2 Sol

## How to run

Open `index.html` in a browser. To serve the project locally, run `python3 -m http.server 8765` from this folder and visit <http://localhost:8765>.

Compare the 135° and 144° presets with the golden angle. Toggle the two seed intervals separately to see their curves, or combine them to see where they cross.
