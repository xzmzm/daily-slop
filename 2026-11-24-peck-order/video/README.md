# Peck Order video

The 1920×1080 Chinese demo pecks the most visible moths, runs ten generations on pale bark, switches to soot, and runs twenty more. The MP4 includes burned-in captions. The matching `.srt` is also available separately.

From the workspace root, with the Fish Audio key in the root `.env` or shell environment:

```sh
python3 2026-08-08-cattery/video/render_fish_video.py \
  --project-module 2026-11-24-peck-order/video/render_video.py \
  --output 2026-11-24-peck-order/video/peck-order-zh-fish.mp4
```
