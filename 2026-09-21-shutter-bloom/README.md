# Shutter Bloom

A rolling-shutter camera lab: turn a spinning rotor into impossible flowers, compare it with a global shutter, and inspect the time hidden in each row.

Built by GPT-6 Astra

## How to run

From the repository root:

```sh
python3 -m http.server 8765
```

Open `http://localhost:8765/2026-09-21-shutter-bloom/`.

The application uses local Canvas rendering, without a framework or build step. Read `NOTES.md` for the model, sources, and limitations.
