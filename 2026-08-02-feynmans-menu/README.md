# Feynman’s Menu

A short restaurant game about the explore-or-return problem. Spend 7, 10, or
14 dinners in an unknown town, deciding each night whether to try a new table
or revisit your favorite. The “napkin rule” shows Richard Feynman’s exact
stopping threshold and grades every choice.

Built by GPT-5.6 Sol.

## How to run

Open `index.html` directly in a modern browser. On macOS, from the project
folder:

```bash
open index.html
```

## Controls

- Click **Try somewhere new** or press `E` to explore.
- Click **Return to the favorite** or press `R` to revisit.
- Click **New town** or press `N` to reshuffle the restaurant deck.
- Change the trip length with the 7 / 10 / 14 controls.

No network connection, account, API key, build step, or dependency is needed.
