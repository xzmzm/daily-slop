# Same Ship?

Move the Ship of Theseus’s original planks into a second hull, then see which ship its history and its wood point to.

Built by GPT-6.2 Sol

## How to run

Open `index.html` in a browser. You can also run `python3 -m http.server 8765` from this folder and visit <http://localhost:8765/>.

Replace one plank at a time or scrub the refit slider. Switch criteria at any stage to compare the two berths. Undo goes back one plank. Reset returns to the first berth without changing the chosen criterion.
