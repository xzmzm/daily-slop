# Turtle 1776 · 海龟号的第一夜

> Built by GLM-5.3

二百五十年前的今晚——1776 年 9 月 6 日夜到 7 日凌晨——军士 Ezra Lee 钻进
布什内尔的「海龟」（Turtle），潜到英舰「鹰」号船底，试着用木钻把火药桶
拧上船壳。这是人类历史上第一次潜艇攻击，那颗手摇螺旋桨也是螺旋桨推进
水上交通工具的第一次记载。本届 250 周年纪念版：一间配平池、一根立方根、
一座二氧化碳钟，和一条由潮流窗口决定成败的攻击航线。

## How to run

直接双击打开 `index.html`，或者：

```bash
python3 -m http.server 8765     # 在仓库根目录
```

然后访问 <http://localhost:8765/2026-09-06-bushnells-turtle/>。
（8000 端口在本机是保留端口，不要用。）

## 四个房间

1. **配平的刀刃** — 十英尺橡木桶按椭球建模：满排水 2.74 吨，干重一吨半，
   中性悬停要往舱底注入 1,150 公斤水。本页最漂亮的一行是气袋恒等式
   `V_air = M_dry/ρ − V_solids`：每公斤铁龙骨买回 0.85 升空气，每公斤
   橡木吃掉 0.36 升——没有八百九十公斤铁，气袋就只剩一口气。丢掉 200 磅
   可释放铅，桶以 0.89 m/s（1.7 kn）应急上浮。
2. **曲柄对潮流** — ITTC 1957 湍流摩擦线 + 拟合形状阻力，稳航速是功率的
   立方根：8 倍功率换 2 倍速度。诚实的巡航是一百瓦曲柄一叉四分之一英里
   每小时；史载「静水三英里」按阻力要 1,452 瓦——那是环法冲刺的腿。
   地面速度 = 曲柄速度 − 潮流，东河两节的流比海龟全力还快。
3. **三十分钟** — 气袋 802 升，先到的永远是呼出的二氧化碳：代谢模型
   `V̇CO₂ = 0.85·(100+4P)/348.3`，56 瓦曲柄正好三十分钟撞上 3% 阈值——
   史书上的那个数；顶钻 130 瓦十六分钟。氧气要到 15% 还得再等二十分钟。
4. **攻击之夜** — 一条确定性航线仿真：捕鲸艇拖带、顶流自摇、一百五十米
   下潜、船底钻孔到 CO₂ 被迫放弃、放雷、四十分钟引信、抢在起爆前登岸。
   潮流按 M2 正弦摆动，出发时刻是唯一的旋钮——23:00 是那晚窗口的最后一格，
   23:30 之后整夜都被潮流收走。1:00 出发则在顶流里耗到天亮。

外加一条 1775–1864 时间线：从耶鲁的木桶、萤火熄灭的试航、鹰之夜、
运输船沉没、木桶鱼雷、《木桶之战》、化名「戴维·布什」的隐居，
到八十八年后「亨利」号第一次真正炸沉军舰。

## Tests

```bash
node --test test_physics.mjs
```

23 个断言组：椭球切片积分、气袋恒等式的两种形式、吃水二分回代、应急
上浮闭式、ITTC 链条与 8P→2v 立方律、56 W 三十分钟规格、CO₂ 恒先于 O₂
（任意功率）、潮流平潮点、史实航线「登岸先于起爆」、错过窗口的失败、
23:00 是最后一格窗口、以及两次仿真逐位相同。

## 史实与重建的边界

尺寸（10×6×3 英尺）、200 磅可释放铅、约 3 mph、约 30 分钟空气、拖带
接近、约两小时顶流、钻不进舵铁垫铁、放雷起爆、总督岛哨兵——都出自
通行记载。橡木/铁/黄铜的质量分配、潮流相位、锚位距离、引信时长是
按这些记载拟合的重建值（见 NOTES.md）。也注明：有海军史家怀疑这次
攻击根本无法完成，记载或出于宣传——物理不裁决，只列出双方都要服从
的约束。
