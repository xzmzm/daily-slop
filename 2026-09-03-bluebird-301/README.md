# Bluebird 301 · 盐上的立方定律

1935 年 9 月 3 日，50 岁的马尔科姆·坎贝尔爵士在邦纳维尔盐滩驾驶 27 英尺长的
Campbell-Railton 蓝鸟（36.7 升机械增压劳斯莱斯 R 型 V12，2,300 马力）跑出
**301.129 mph** —— 人类第一次在陆地上突破 300 英里每小时。这是 91 周年纪念的
一座速度物理工作室：整课都是闭式公式。

五个房间：

1. **那一英里** —— 飞驰测量英里的实时两趟纪录挑战：百分之一秒秒表、
   风对两趟的不对称影响、以及最终成绩为什么是两趟速度的**调和平均**
   （一阶风差抵消，只剩 w²/v 的二阶损耗）。
2. **立方定律** —— P = ½ρC_dA v³ 的双对数图：速度 ×2 要功率 ×8；
   1898→1935 速度 ×7.68 = 功率 ×452。推力机器的 F·v 等效功率点画在同一张图上。
3. **极限速度** —— 稳态就是一个三次方程 a v³ + b v = P，用**卡尔达诺 1545 年
   的显式解**当场解出，与 200 次二分法对答案；外加海拔账本（ISA 密度公式）：
   邦纳维尔的稀薄空气帮风阻 −12%，机械增压让功率不缩水 —— 这就是纪录从
   代托纳沙滩搬到盐滩的原因。
4. **轮缘的张力** —— 301 mph 时车轮 ~2,737 rpm（比发动机还快），轮缘向心
   加速度 v²/r ≈ **3,937 g**：一粒 28 g 的盐渣压着轮缘相当于 110 公斤。
5. **纪录阶梯** —— 1898（电动车！）到 1997（超音速 ThrustSSC）的绝对纪录
   时间线，活塞、涡轮、火箭、喷气分色；1935 那枚五角星是今天。

引擎参数是史实（功率、车重、海拔、成绩）；风阻与滚阻是拟合参数，调到卡尔达诺
解恰好落在 301.129 mph 上（测试锁定 ±0.5 mph）。四个预设（1899 电动车、
1927 代托纳、1935 蓝鸟、1947 科布）各自复现自己的真实纪录。

## How to run

零依赖、无构建。因为用了 ES modules，需要起一个本地静态服务（别用 8000 端口）：

```bash
python3 -m http.server 8765        # 在仓库根目录
# 打开 http://localhost:8765/2026-09-03-bluebird-301/
```

跑引擎测试（23 项，全部是精确断言）：

```bash
cd 2026-09-03-bluebird-301 && node --test test_physics.mjs
```
