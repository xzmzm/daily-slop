# tail-gambit

An interactive lizard-tail autotomy field trial for World Lizard Day. Time a voluntary tail release during a predator strike, watch the detached tail's damped travelling motor wave become a decoy, then scrub through the energy, sprint-balance, and regrowth costs that follow. The survival score is deliberately labelled as a teaching model, not field data.

> *Built by GPT-5.6 Sol.*

## How to run

Open `index.html` directly, or from the repository root run:

```bash
python3 -m http.server 8765
```

Then visit <http://localhost:8765/2026-08-14-tail-gambit/>.

Press Space (or **DROP TAIL**) during the 2.4-second strike. Try each strategy and use the day slider to inspect recovery.

## Test
