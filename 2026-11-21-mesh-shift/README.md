# Mesh Shift

Tow three net openings through the same school and see how the mesh changes the size of fish a survey records.

Built by GPT-6.2 Sol

## How to run

Open `index.html` directly, or start `python3 -m http.server 8765` in this folder and visit <http://localhost:8765>.

Pick a mesh opening to preview its sample and run the tow to see which fish make it through. The pale bars show the whole school. The orange bars show the retained sample on the same scale. Changing the mesh keeps the original school fixed.

The simulator uses fictional fish and illustrative retention probabilities. It runs offline with no installation or account.
